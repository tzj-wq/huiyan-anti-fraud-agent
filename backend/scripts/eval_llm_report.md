# LLM-as-Judge 冲突仲裁评估报告

- 模型：deepseek / deepseek-v4-flash（temperature=0.2，推理模型；生产预算 3.0s / 评估预算 15.0s，失败自动回退规则仲裁）
- 子集：120 笔触发仲裁的交易（CONFLICT/BORDERLINE），FRAUD 60 / LEGIT 60，与主评估同一数据集（seed=20250901）
- 决策一致率（规则 vs LLM 仲裁后最终决策）：75.0%

## 1. 仲裁效果对比（同一子集，对 ground truth）

| 仲裁方式 | Precision | Recall | F1 | 误报 | 漏报 |
|---|---|---|---|---|---|
| 规则仲裁 | 0.711 | 0.983 | 0.825 | 24 | 1 |
| LLM-as-Judge | 0.545 | 1.000 | 0.706 | 50 | 0 |

## 2. 决策改变分析

- PASS->REVIEW：27 笔
- REVIEW->BLOCK：3 笔
- 标签感知质量：改变且更正确 4 笔 / 改变且更错误 26 笔
- LLM 原始升级动作分布：{'NONE': 1, 'ESCALATE_REVIEW': 79, 'ESCALATE_BLOCK': 4}

## 3. LLM 调用质量

- 解析成功率（评估预算 15.0s）：70.0%（84/120）
- 生产预算（3.0s）内成功率：0.0%（0/120）——超出部分为超时自动回退规则仲裁，生产链路不受影响
- 双预算均失败：36 笔
- 成功调用延迟：平均 8933 ms / P50 8718 ms / P99 15786 ms

## 4. 仲裁理由样例

- graph-trace离群且置信较低，降权；但其关联风险节点和对私转账因素需谨慎，升级人工复核。
- 设备复用异常且跨地大额交易，关联风险节点，名单未命中不足以排除，需人工复核。
- 多名高置信Agent指向设备、图簇及大额行为风险；list-match低分离群且证据不充分应降权。综合风险偏高，保守转人工复核。

## 注记

- temperature=0.2 下的点估计，复跑存在方差；子集与规则仲裁输入完全相同，对比公平
- 安全基线：LLM 裁决经合并层约束——规则侧的升级结论不可被 LLM 降低，降级剔除与法定人数保护恒定生效
