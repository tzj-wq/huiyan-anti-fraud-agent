# 慧眼识诈协同决策引擎离线评估报告

- 数据集：4000 笔确定性生成标注交易（FRAUD 2000 / LEGIT 2000），分层 70/30 划分（测试集 1200 笔），LLM 关闭、规则仲裁
- 阳性定义：决策为 REVIEW 或 BLOCK；单 Agent 在训练集上选择、测试集上报
- AUC 口径：规则系统取连续融合分（静态=算术加权分，多 Agent 协同=置信度加权融合分，不含仲裁升级与一票否决），分类器取预测概率

## 1. 数据集与防泄漏审计

| 单特征 | AUC |
|---|---|
| 对私陌生人 | 0.812 |
| amount | 0.804 |
| 风险设备(X结尾) | 0.769 |
| 异地交易 | 0.753 |
| 风险商户 | 0.725 |
| 夜间交易 | 0.710 |
| 私人转账渠道 | 0.697 |
| 黑名单命中 | 0.550 |

- 金额重叠：欺诈小额（<2 万）占比 14.4%（试探型），正常大额（>30 万）占比 4.5%——金额不是判别捷径
- 黑名单：仅覆盖 10% 的欺诈，正常交易命中 0 笔
- 身份-标签独立性（偏离基率最大值）：user 0.071 / merchant 0.017 / device（类型内）0.039
- 结构子人群：{'standard': 3600, 'blacklist': 200, 'weak_alarm': 200}
